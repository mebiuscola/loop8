## 1. 核心思路

现在的四个标签（本周材料 / 材料阅读 / 课堂讲稿 / Deep Dive）是按**功能**分的，导致同一件事散在几处：
一节课的字幕在"本周材料"，讲稿在"课堂讲稿"，它的 Deep Dive 又在"Deep Dive"里切到"本节课"。

新方案按**你一周里实际面对的东西**来分，和 `PRODUCT.md` 的数据结构一一对应：

```
一周课程
├── 材料（BB 介绍、课件、参考文献）——课前读，所有课堂共用
├── 课堂（Lecture / Seminar …）——课后：字幕 → 讲稿 → 本节 Deep Dive
└── 整周 —— 把材料和选中的课堂合起来的整周 Deep Dive
```

再加三样**全局**的东西：课程列表、后台任务、Ask。设置是独立页面。

原则：

1. **每个对象只有一个家。** 课件只在"阅读"里读；一节课的一切都在这节课的页面里。
2. **每一项只显示一个状态 + 一个下一步。** 细节折叠起来。
3. **框架固定不动。** 课程列表、工作区导航、任务指示、Ask 的位置在任何页面都不变，不随滚动或提示条移动。
4. **四种内容一眼可分**（原页 / 译文 / 课堂发言 / AI 分析），用固定的标签和底色区分，全应用统一。

## 2. 整体框架

```
┌────────────┬──────────────────────────────────────────────┬──────────────┐
│ Classroom  │ DebateW4 ▾     概览  阅读  课堂  整周   ⟳ 2 个任务 │              │
│            ├──────────────────────────────────────────────┤   Ask        │
│ 每周课程    │                                              │  （可收起）   │
│ ● VisualW8 │                                              │              │
│ ⚠ EncW8    │              当前工作区内容                     │  范围：       │
│ ● DebateW8 │                                              │  [本周 ▾]    │
│ ⚠ EncW7    │                                              │  [第 3 页 ×] │
│   …        │                                              │              │
│            │                                              │  历史（全部，  │
│ + 新建一周  │                                              │  每条标范围）  │
│            │                                              │              │
│ ⚙ 设置     │                                              │  [输入问题]   │
│ v2.25.17   │                                              │              │
└────────────┴──────────────────────────────────────────────┴──────────────┘
```

- **左栏：课程列表。** 默认展开，可收起（阅读时可一键收起）。每门课前面一个状态点：
  `●` 全部就绪 / `⟳` 有任务在跑 / `⚠` 有停止或失败的任务。（问题 1、21）
- **顶栏：** 当前课程名 + 四个工作区 + 后台任务指示。**固定在顶部，不随页面滚动。**（问题 4、29）
- **右栏：Ask。** 默认并排停靠，不盖住内容；可收起成一个按钮。（问题 18、30）
- **设置：** 左栏底部唯一入口，打开独立页面而不是弹窗。版本号从 `package.json` 读取。（问题 2、3、20）
- **网址记录位置：** 例如 `#/w/DebateW4/read/<材料>/p/3`，刷新或返回后回到原处。

### 后台任务

顶栏的"⟳ 2 个任务"点开是一个任务面板，汇总**所有课程**的任务（项目对象的 `tasks`、ACP 任务、ChatGPT 任务统一成一个列表，见 `API.md` 末尾第 2 条）：

```
后台任务
 ⟳ DebateW8 · 课件导读 · Lecture 1.pptx      页 12/30      [停止]
 ⟳ EncW7 · 文献翻译 · 某份文献                段 120/240    [停止]
 ⚠ EncW8 · 课件检查 · 已停止，6/13 已保存                  [继续] [去看看]
 ✓ DebateW4 · 本节讲稿 · Lecture                10 分钟前
```

出错时：**在出错的那一项旁边**显示原因和按钮（如"去设置模型"、"继续"），任务面板里同时记一条。不在页面顶部插入横幅。（问题 6）

### 统一的状态词

全应用只用这几种状态，颜色固定：

| 状态 | 例 | 说明 |
|---|---|---|
| 未开始 | 未翻译 | 灰 |
| 进行中 | 翻译中 120/240 | 带进度 |
| 已停止 | 已停止 · 41/240 已保存 · 可继续 | 醒目，必须写出已保存多少（问题 26） |
| 失败 | 失败 · 模型过滤 | 写出原因和下一步 |
| 已完成 | 已翻译 | 绿 |
| 已过期 | 材料已变更 · 建议更新 | 原件改了，结果还是旧的 |

一项只显示一个状态。（问题 7、23）

## 3. 四个工作区

### 3.1 概览 —— "这周进行到哪了"

替代现在的"本周材料"。打开一门课默认进入这里（或回到上次的位置，见问题 Q3）。

```
DebateW4                                                  [+ 添加文件]（也可直接拖进来）

材料                                                     课前
 BB   课程介绍                     已保存                     [查看]
 PPT  Lecture 1.pptx              已完成导读 30/30           [阅读]
 PDF  某份参考文献                  未翻译                     [翻译]
 PDF  另一份参考文献                已停止 · 41/240 已保存      [继续]
 ⋯ 每行右侧 ⋯ 菜单：改用途 / 下载原件 / 高级（导入 JSON、清缓存、重新解析）/ ── / 删除

课堂                                                     课后
 Lecture · Lecture 1   字幕 ✓  录音 ✓   讲稿 ✓   Deep Dive 未生成   [打开]
 Seminar · Seminar 2   字幕 ✓  录音 ✓   讲稿 ✓   Deep Dive ✓        [打开]
 [+ 添加一节课]

整周                                                     周末
 整周 Deep Dive        已完成（含 2 节课）                 [打开]
```

- 每份材料**都显示翻译/导读状态**，而不只是"JSON 已就绪"。（问题 24）
- 技术日志（模型诊断、分批检查）收进"详情"，默认不显示。（问题 22）
- 危险操作单独分组放在菜单最后。（问题 8）
- 底部那两行规则小字去掉，改成需要时出现的说明。（问题 10）

### 3.2 阅读 —— 课件和参考文献

课件和参考文献合在一个阅读器里，左侧是本周材料清单（带状态），右侧是阅读区。（问题 25）

```
┌─────────────────┬──────────────────────────────────────────────────────┐
│ 课件             │ Lecture 1.pptx       ‹ 3 / 30 ›   [原页|译文|细读]  ⋯ │
│ ✓ Lecture 1     ├──────────────────┬───────────────────┬───────────────┤
│ ✓ Seminar       │ 原页（固定）       │ 双语译文            │ 细读（AI）     │
│ 参考文献          │ ┌──────────────┐ │ EN 段落             │               │
│ ○ 文献 A  未翻译  │ │              │ │ 中文译文            │               │
│ ◐ 文献 B  41/240 │ │   第 3 页     │ │ …                  │               │
│                 │ │              │ │                    │               │
│                 │ └──────────────┘ │                    │               │
│                 │  加载中… 的占位    │                    │               │
└─────────────────┴──────────────────┴───────────────────┴───────────────┘
```

- **原页在本页范围内固定可见**，读长译文时不会滚走；页码标在每页开头。（问题 12、28）
- 原页加载时显示占位，不是空白。（问题 27）
- 还没生成的栏位显示"尚未生成导读 · [生成]"，而不是空白。（问题 11）
- 工具栏只放阅读相关的：翻页、显示哪几栏、缩放。材料操作（重新加载预览、关联导出的 PDF、试解析本页）放到 ⋯ 的"高级"里。（问题 13）
- 参考文献没有时，空状态里直接给上传按钮。（问题 16）
- 在阅读时，Ask 的范围自动是"这份材料 · 第 3 页"，可以改。

### 3.3 课堂 —— 一节课的全部

一节课一个页面：上传、讲稿、本节 Deep Dive 都在这里。（问题 9）

```
Lecture · Lecture 1    [讲稿] [本节 Deep Dive]             字幕 ✓ 录音 ✓  ⋯
┌──────────────────────────────────────────────────────┬────────────────┐
│ 00:04  Lecturer                                       │ 目录            │
│ EN 原段 …                                             │ · 小节 1        │
│ 中文对照 …                                             │ · 小节 2        │
│                                                       │ · 小节 3        │
│ 02:37  Student                                        │                │
│ …                                                     │                │
├──────────────────────────────────────────────────────┴────────────────┤
│ ▶ 2:37 / 44:27  ───●────────────   -10s +10s  1×  跟随讲稿  回到当前段   │  ← 占位，不遮挡正文
└────────────────────────────────────────────────────────────────────────┘
```

- **播放器占自己的一行**，不浮在正文上；保留现有的全部控制（跳转、倍速、跟随、回到当前段、播放位置恢复）。（问题 30）
- 讲话人标签 Lecturer / Student / Unclear 明显可见（`PRODUCT.md` 的要求）。
- 还没有字幕时，页面就是上传区；有字幕没讲稿时，显示"生成讲稿"（不自动开始）。
- "本节 Deep Dive"是这节课的第二个标签，不再和整周混在一起。（问题 17）

### 3.4 整周 —— 整周 Deep Dive

```
整周 Deep Dive                                  已完成 · 2026-10-27   [更新] [下载]
纳入范围：☑ 教学材料（1 份）  ☑ Lecture 1  ☑ Seminar 2  ☐ 没有讲稿的课堂（不可选）
──────────────────────────────────────────────────────────────────
（正文）
```

- 范围选择收成一行，正文占主要位置。

## 4. 主要流程

**A. 课前：** 新建一周 → 在"概览"拖入 BB / PPT / Readings → 每一项显示下一步（"生成导读""翻译"）→ 点了之后在后台跑，可以立刻去"阅读"读已完成的部分。

**B. 课后：** 概览或课堂页 → 添加 Lecture / Seminar → 上传 SRT（可选录音）→ "生成讲稿" → 在同一页读讲稿 → 需要时"生成本节 Deep Dive"。

**C. 周末：** 整周 → 勾选纳入的课堂 → "生成整周 Deep Dive"。

**D. 提问：** 任何页面都能在右栏提问，范围跟随当前位置（本周 / 某节课 / 某份材料某页），可手动改；历史始终全部可见，每条标出当时的范围。（问题 31）

**E. 出问题时：** 左栏课程前出现 ⚠ → 进入后在"概览"里对应那一项写明原因和"继续" → 继续时复用已保存的部分。

**F. 删除：** 保持两步：先显示影响（"会删除哪些结果"），确认后执行（AGENTS.md 规则 7）。

## 6. 迁移顺序

新前端挂在 `/next`，旧前端在 `/` 保持可用，逐个替换：

1. **框架**：课程列表、顶栏、任务面板、统一状态（后面每个工作区都要用）
2. **阅读**（课件 + 参考文献）
3. **设置**
4. **课堂**（讲稿 + 本节 Deep Dive）
5. **概览** 和 **整周**
6. 全部完成后，`/` 指向新前端，旧前端删除

和交接文档原定的"材料阅读 → 设置 → 讲稿 → Deep Dive"一致，只是在最前面加了"框架"。

## 8. 需要你决定的问题

- **Q1. 课件和参考文献合并进一个"阅读"清单**，还是保留"课件 / 参考文献"两个分开的入口？
- **Q2. 本节 Deep Dive 移到"课堂"页里**（和讲稿并列），可以吗？
- **Q3. 打开一门课时**，默认进入"概览"，还是回到你上次看的地方（例如上次读到的课件第 12 页）？
- **Q4. Ask 默认停在右侧并排**（占一部分宽度），还是默认收起、需要时再打开？
- **Q5. 你平时最常从哪里开始？** 例如课前主要读课件、课后主要看讲稿——这会决定哪个工作区排在最前、迁移先做哪个。
- **Q6.** 还有没有现在界面里**找不到但想要的功能**，或者**觉得多余可以去掉的东西**？
