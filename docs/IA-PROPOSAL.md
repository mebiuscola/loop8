# 新前端信息架构方案

> 2026-11-21 · 依据：`PRODUCT.md`、`docs/API.md`、`docs/UI-ISSUES.md`（31 条）。
> 这里定"有哪些页面、每页放什么、怎么从一步走到下一步"。视觉细节在实现每个工作区时细化。
> **状态：已确认。** 用户对第 8 节 6 个问题的回答已写入正文；其余细节由开发助手按"操作顺手、界面一致"的目标决定。

---

## 1. 核心思路

保留用户熟悉的四个工作区，但把每个工作区里"散落、重复、矛盾"的地方理顺：

```
一周课程
├── 概览      这周进行到哪了：材料、课堂、Deep Dive 的状态和下一步（替代"本周材料"）
├── 阅读      课件 / 参考文献（两个分开的入口）
├── 课堂      某一节课：字幕、录音、讲稿
└── Deep Dive 本节 Deep Dive 和整周 Deep Dive
```

再加三样**全局**的东西：课程列表、后台任务、提问（Ask）。设置是独立页面。

原则：

1. **每个对象只有一个家。** 上传和状态汇总在"概览"；读课件在"阅读"；读讲稿在"课堂"；读分析在"Deep Dive"。其他地方只放跳转链接，不重复放操作按钮。
2. **每一项只显示一个状态 + 一个下一步。** 细节折叠起来。
3. **框架固定不动。** 课程列表、工作区导航、任务指示、提问按钮的位置在任何页面都不变，不随滚动或提示条移动。
4. **四种内容一眼可分**（原页 / 译文 / 课堂发言 / AI 分析），用固定的标签和底色区分，全应用统一。
5. **回到上次的位置。** 打开一门课时，回到上次在这门课看的工作区、材料和页码；第一次打开时进入"概览"。

## 2. 整体框架

```
┌────────────┬──────────────────────────────────────────────────────────┐
│ Classroom  │ DebateW4      概览  阅读  课堂  Deep Dive    ⟳ 2 个任务  提问 │
│            ├──────────────────────────────────────────────────────────┤
│ 每周课程    │                                                          │
│ ● VisualW8 │                                                          │
│ ⚠ EncW8    │                   当前工作区内容                            │
│ ● DebateW8 │                                                          │
│ ⚠ EncW7    │                                                          │
│   …        │                                                          │
│ + 新建一周  │                                                          │
│ ⚙ 设置     │                                                          │
│ v2.25.17   │                                                          │
└────────────┴──────────────────────────────────────────────────────────┘
```

- **左栏：课程列表。** 默认展开，可收起；收起状态会被记住。每门课前面一个状态点：
  `●` 全部就绪 / `⟳` 有任务在跑 / `⚠` 有停止或失败的任务。（问题 1、21）
- **顶栏：** 当前课程名 + 四个工作区 + 后台任务 + 提问按钮。**固定在顶部，不随页面滚动。**（问题 4、29）
- **设置：** 左栏底部唯一入口，打开独立页面而不是弹窗。版本号从 `package.json` 读取。（问题 2、3、20）
- **网址记录位置：** 例如 `#/w/DebateW4/read/ppt/<材料>/p/3`，刷新、返回、重新打开都回到原处。

### 提问（Ask）

- **默认收起**，顶栏"提问"按钮打开。
- 打开后**停靠在右侧，把内容区挤窄，不盖住内容**；再点一次收起。是否打开会被记住。（问题 18、30）
- 范围跟随当前位置（本周 / 某节课 / 某份材料某页），顶部显示为可去掉、可修改的标签。
- 历史**始终全部可见**，每条标出当时的范围；当前范围的问答高亮。（问题 31）

### 后台任务

顶栏的"⟳ 2 个任务"点开是一个任务面板，汇总**所有课程**的任务（项目对象的 `tasks`、ACP 任务、ChatGPT 任务统一成一个列表，见 `API.md` 末尾第 2 条）：

```
后台任务
 ⟳ DebateW8 · 课件导读 · 某份课件               页 12/30      [停止]
 ⟳ EncW7 · 文献翻译 · 某份文献                  段 120/240    [停止]
 ⚠ EncW8 · 课件检查 · 已停止，6/13 已保存                    [继续] [去看看]
 ✓ DebateW4 · 讲稿 · Lecture 1                   10 分钟前
```

出错时：**在出错的那一项旁边**显示原因和按钮（如"去设置模型""继续"），任务面板里同时记一条。不在页面顶部插入横幅。（问题 6）
没有任务时，顶栏只显示一个安静的图标，不占位置。

### 统一的状态词

全应用只用这几种状态，颜色固定：

| 状态 | 例 | 说明 |
|---|---|---|
| 未开始 | 未翻译 | 灰 |
| 进行中 | 翻译中 120/240 | 带进度 |
| 已停止 | 已停止 · 41/240 已保存 · 可继续 | 醒目，必须写出已保存多少（问题 26） |
| 失败 | 失败 · 模型过滤 | 写出原因和下一步 |
| 已完成 | 已翻译 | 绿 |
| 已过期 | 材料已变更 · 建议更新 | 原件改了，结果还是旧的 |

一项只显示一个状态。（问题 7、23）

### 统一的操作位置

- 每个页面右上角最多一个**主按钮**（当前最该做的那件事，如"生成讲稿"）。
- 次要操作放在 `⋯` 菜单，菜单分组：常用 / 下载 / 高级 / ──── / 删除。
- 生成类按钮不用 `↗`；`↗` 只给真正打开新窗口的链接。（问题 14）
- 所有删除都两步：先显示影响，确认后执行（AGENTS.md 规则 7）。

## 3. 四个工作区

### 3.1 概览 —— "这周进行到哪了"

替代现在的"本周材料"。上传、改用途、删除都在这里。

```
DebateW4                                                  [+ 添加文件]（也可直接拖进来）

材料                                                     课前
 BB   课程介绍                      已保存                    [查看]
 PPT  课件 1                       已完成导读 30/30          [阅读]
 PDF  参考文献 A                    未翻译                    [翻译]
 PDF  参考文献 B                    已停止 · 41/240 已保存     [继续]

课堂                                                     课后
 Lecture · Lecture 1   字幕 ✓  录音 ✓   讲稿 ✓   本节 Deep Dive 未生成   [打开]
 Seminar · Seminar 2   字幕 ✓  录音 ✓   讲稿 ✓   本节 Deep Dive ✓        [打开]
 [+ 添加一节课]

整周                                                     周末
 整周 Deep Dive        已完成（含 2 节课）                                 [打开]
```

- 每份材料**都显示翻译/导读状态**，而不只是"JSON 已就绪"。（问题 24）
- 技术日志（模型诊断、分批检查）收进"详情"，默认不显示。（问题 22）
- 改用途、下载原件放在 `⋯` 的常用组；导入 JSON、清缓存、重新解析放"高级"；删除单独在最后。（问题 8）
- 底部那两行规则小字去掉，改成需要时出现的说明。（问题 10）
- 一节课的字幕和录音在这里上传；"打开"进入"课堂"。（问题 9）

### 3.2 阅读 —— 课件 / 参考文献

保留"课件"和"参考文献"两个分开的入口。两边结构相同：

```
[课件] [参考文献]    课件 1 ▾（下拉项带状态）    ‹ 3 / 30 ›    显示：☑原页 ☑译文 ☑细读   [主按钮] ⋯
┌────────────────────┬──────────────────────┬──────────────────┐
│ 第 3 页             │ 双语译文               │ 细读（AI）         │
│ ┌────────────────┐ │ EN 段落                │                  │
│ │  原页（固定）    │ │ 中文译文               │                  │
│ │                │ │ …                     │                  │
│ └────────────────┘ │                       │                  │
└────────────────────┴──────────────────────┴──────────────────┘
```

- 材料下拉框每一项带状态（已完成 / 未翻译 / 已停止 41/240）。（问题 25）
- **原页在本页范围内固定可见**，读长译文时不会滚走；页码标在每页开头。（问题 12、28）
- 原页加载时显示占位，不是空白。（问题 27）
- 还没生成的栏位显示"尚未生成导读 · [生成]"，而不是空白。（问题 11）
- 工具栏只放阅读相关的：翻页、显示哪几栏、缩放、专注阅读（收起左栏）。重新加载预览、关联导出的 PDF、试解析本页等放进 `⋯` 的"高级"。（问题 13、15）
- 没有参考文献时，空状态里直接给上传按钮。（问题 16）

### 3.3 课堂 —— 读一节课的讲稿

```
[Lecture 1 ▾]   字幕 ✓ 录音 ✓ 讲稿 ✓                    [更新讲稿] ⋯（补充字幕/录音、下载）
┌──────────────────────────────────────────────────────┬────────────────┐
│ 00:04  Lecturer                                       │ 目录            │
│ EN 原段 …                                             │ · 小节 1        │
│ 中文对照 …                                             │ · 小节 2        │
│ 02:37  Student                                        │ · 小节 3        │
├──────────────────────────────────────────────────────┴────────────────┤
│ ▶ 2:37 / 44:27  ───●────────────   -10s +10s  1×  跟随讲稿  回到当前段   │  ← 自己占一行，不遮挡正文
└────────────────────────────────────────────────────────────────────────┘
```

- **播放器占自己的一行**，不浮在正文上；保留现有的全部控制（跳转、倍速、跟随、回到当前段、播放位置恢复）。（问题 30）
- 讲话人标签 Lecturer / Student / Unclear 明显可见（`PRODUCT.md` 的要求）。
- 没有字幕时显示上传区；有字幕没讲稿时显示"生成讲稿"（不自动开始）。
- 顶部有链接"查看本节 Deep Dive"，跳到 Deep Dive 工作区对应的这节课。

### 3.4 Deep Dive —— 本节和整周

去掉现在"本节课 / 本周课"切换加重复标签的结构，改成左侧一个清单：

```
┌──────────────────────┬───────────────────────────────────────────────────┐
│ 整周 Deep Dive    ✓   │ 整周 Deep Dive          已完成 · 10-27   [更新] ⋯   │
│ ──────────────────── │ 纳入：☑ 教学材料 ☑ Lecture 1 ☑ Seminar 2           │
│ Lecture 1        未生成 │ ─────────────────────────────────────────────── │
│ Seminar 2         ✓   │ （正文）                                          │
└──────────────────────┴───────────────────────────────────────────────────┘
```

- 选"整周"看整周；选某节课看本节 Deep Dive。每项带状态。（问题 17）
- 范围选择收成一行，正文占主要位置。
- 没有讲稿的课堂在清单里显示"需要先生成讲稿"，并链接到"课堂"。

## 4. 主要流程

**A. 课前：** 新建一周 → 在"概览"拖入 BB / PPT / Readings → 每一项显示下一步（"生成导读""翻译"）→ 后台运行，可以立刻去"阅读"读已完成的部分。

**B. 课后：** 概览 → 添加 Lecture / Seminar → 上传 SRT（可选录音）→ "打开"进入"课堂" → "生成讲稿" → 读讲稿 → 需要时点"查看本节 Deep Dive"去生成。

**C. 周末：** Deep Dive → 整周 → 勾选纳入的课堂 → "生成整周 Deep Dive"。

**D. 提问：** 任何页面点"提问"，范围跟随当前位置，可手动改。

**E. 出问题时：** 左栏课程前出现 ⚠ → 任务面板或"概览"里对应那一项写明原因和"继续" → 继续时复用已保存的部分。

**F. 删除：** 两步：先显示影响，确认后执行。

## 6. 迁移顺序

新前端挂在 `/next`，旧前端在 `/` 保持可用，逐个替换：

1. **框架**：课程列表、顶栏、任务面板、提问面板、统一状态和按钮（后面每个工作区都要用）
2. **阅读**（课件 + 参考文献）
3. **设置**
4. **课堂**
5. **Deep Dive**
6. **概览**（在它完成前，新前端的上传等操作链接到旧界面）
7. 全部完成后，`/` 指向新前端，旧前端删除
