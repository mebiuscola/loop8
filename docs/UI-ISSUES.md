## 开发备注：真实数据后端核查（2026-11-21，data/ 副本）

没有发现需要修复的后端缺陷。核查结果：

1. **参考文献进度少计（旧数据，低优先级）。** 某份文献 11-05 翻译到第 42 段时因 content_filter 停止。当时的版本还没有 `Parsed/<id>/reference-translation.json` 检查点，已完成的 41 段只存在 `Parsed/.pipeline.json` 的模型缓存里。`referenceProgress()` 不读缓存，所以 `reference-reader` 返回 0 段；`translateReference()` 继续时会先导入缓存，不会丢失也不会重复请求。新版本每段都写检查点，不会再出现。如要让旧数据显示正确进度，可在 `referenceProgress()` 中读取缓存条目，需配测试。
2. **生成状态与文件一致。** 9 节课的讲稿、本节 Deep Dive、整周 Deep Dive 状态和 `Output/` 中的文件一一对应；字幕覆盖率全部 100%。
3. **旧格式兼容正常。** 缺少 `artifactStatus` 字段的旧课堂，讲稿和 Deep Dive 都能正常显示。
4. **时间戳跳转正常。** 点击讲稿时间戳，录音定位到对应秒数并播放。
5. 三个停止/失败的任务：手动停止的课件检查（界面有"继续检查"）和 content_filter 停止的文献翻译（界面有"补译剩余"）都保留了已完成部分；PPT 解析未完成的那一门未在界面中逐项核对。
