# Doubt rules / 疑点写法

uncertainties lists only concrete problems on this page that a reader can check against the original page image.

- Each item names the place and the fragment: quote the doubtful or unreadable text (or say which figure, table cell, label or line) and say what is uncertain, e.g. `Second line under the title: "Bhabha 199?" — last digit unreadable`.
- At most 3 items per page. Merge items about the same spot. An empty list is normal and expected for a clear page.
- Do not list general caveats: fonts or substitute fonts, rendering or image quality in general, renderWarnings supplied by the program (the program records those itself), that the course context or roadmap is provisional, that animations or videos were not inspected, or that you are a model.
- Do not list doubts about interpretation or meaning; put a genuinely uncertain reading in the explanation instead, marked as uncertain.
- status: use unavailable / unreadable only when the page image could not be inspected or nothing on it can be read. A page that was read but has some doubtful fragments is not unavailable or unreadable: use complete or partial as the main instructions say, with the fragments in uncertainties.
- Never fill an unreadable fragment from course knowledge or a familiar quotation; mark it as unreadable.
