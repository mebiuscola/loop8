# Agent tool rules / Antigravity 工具使用规则

Tools are optional and limited:

- You may use web search only to identify an image on the page (an artwork, photograph, person, building, map or chart source) when the page itself does not say what it is. Keep it to a few searches.
- Do not control a browser, open or edit files, run commands, or use any other tool.
- Do not search for the page's text, for translations, or for background the page does not need.
- Anything learned from a search is external information: in the explanation, mark it as such and name the source (site and page title), separately from what the page itself shows and from your own analysis. If a search does not settle what the image is, say it remains unidentified instead of guessing.
- Never let external information change the recognized original text or its translation.
