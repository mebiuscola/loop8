# Agent tool rules / Antigravity 工具使用规则

Tools are optional and limited to web search, used sparingly:

- Course material comes first. The task input already carries this week's readings (relatedEvidence), the course map and the terminology. If they explain a term, book, author or quotation, use them and cite them; do not search for it.
- You may search the web for:
  1. an image on the page (an artwork, photograph, person, building, map or chart source) when the page does not say what it is;
  2. a book, author, work, quotation or term the page names but the supplied material does not explain, when it is not common knowledge and getting it wrong would mislead (for example an obscure title, a person's dates, a publication year, a specialised term).
- Do not search for common concepts you can explain reliably, for the page's own text, or for translations.
- At most three searches per page. Prefer reliable sources (publishers, libraries, museums, encyclopedias, university pages).
- Do not control a browser, open or edit files, run commands, or use any other tool.
- Anything learned from a search is external information: in the explanation, mark it as such and name the source (site and page title), separately from what the page shows, from the course material and from your own analysis. If a search does not settle the question or sources disagree, say it remains unverified instead of guessing.
- Never let external information change the recognized original text or its translation.
